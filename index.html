Day 1: Arithmetic Gaps

The Power of **

In Math, we write $2^3$. In Python, we use double asterisks **. It means "multiply the number by itself X times."

print(2 ** 3) # 2 * 2 * 2 = 8
print(5 ** 2) # 5 * 5 = 25 (Squared)
🏠 Real World: To find the Area of a square room that is 6 meters long, you calculate 6 ** 2.

What is 10 ** 3?

Day 3: Logical Operators

The VIP Judge: in

We know ==, but Python has a super-cool way to check if an item is inside a collection: the in operator.

bag = ["Sword", "Shield", "Potion"]
print("Sword" in bag) # True
print("Axe" not in bag) # True

Day 4: String Slicing

Cutting through Strings

Think of a string like a chocolate bar. We can take a "slice" using [start : stop].

word = "PYTHON"
print(word[0:3]) # Cuts from index 0 to 2. Output: "PYT"
print(f"Learning {word} is fun!") # f-string!
🍫 Rule: The first number is where you start. The second number is where you stop before. [0:3] takes index 0, 1, and 2.

If name = "Mastery", what is name[0:4]?

Day 8: Dictionaries

The Key to Data

Dictionaries store data in Key : Value pairs. It's like a real dictionary: Word (Key) and Definition (Value).

student = {
    "name": "Alex",
    "age": 13,
    "grade": 7
}
print(student["name"]) # Alex
📇 RPG Item: {"item": "Sword", "power": 50}. You look up the power by using the word "power".
